# 自动初翻接口调研

核对日期：2026-10-15（Asia/Shanghai）。仅阅读第一方文档、项目代码库与公开模型索引；未注册服务、安装软件、调用翻译接口或发送游戏文本。以下为 9 条要点。

1. **免密钥网页接口可以试用，但不等于稳定。** XUnity.AutoTranslator 现行 README 将 GoogleTranslate、GoogleTranslateV2、BingTranslate 明确标为不稳定，并提示这些无需认证的在线方式可能随时失效。不能向朋友保证安装后永久零配置可用；网络可达性与当前是否正常均尚未实际测试。[XUnity 官方说明](https://github.com/bbepis/XUnity.AutoTranslator#translators)

2. **缓存和自定义接口已有基础。** XUnity 会把翻译结果保存在内存及磁盘，避免重复请求；有 CustomTranslate 和自定义翻译器接口。CustomTranslate 要求特定 GET 参数及纯文本返回，不能随便填一个服务网址便直接兼容。专用插件可以采用类似结构，将“已验收译文”和“自动草稿缓存”分开维护。[缓存机制](https://github.com/bbepis/XUnity.AutoTranslator#spam-prevention)、[自定义翻译器](https://github.com/bbepis/XUnity.AutoTranslator#implementing-a-translator)

3. **Azure Translator：需要用户自己的资源与认证。** 通常使用 Azure Translator 资源密钥，或其他受支持认证方式；当前官方价页的 F0 免费层为每月 **200 万字符**，有免费层仍须配置账户/资源。选用非免费定价层后的费用不能用 XUnity README 旧价保证。[官方认证文档](https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/reference/authentication)、[当前官方价页](https://azure.microsoft.com/en-us/pricing/details/translator/)

4. **百度通用文本翻译：需要自己的 APPID 和密钥。** 当前开通页及接入服务说明列标准版 **每月 5 万字符、每秒 1 次**；个人认证高级版 **每月 100 万字符、每秒 10 次**，企业认证尊享版 **每月 200 万字符**。产品首页仅说认证后“最高每月 200 万”，旧接口页面又存在不同表述；应以实际开通版本及控制台显示权益为准，不能笼统承诺个人账户都有 200 万或无限免费。本次未登录核查个人账户权益。[开通页](https://fanyi-api.baidu.com/access/0/1)、[接入服务说明](https://fanyi-api.baidu.com/doc/13)、[产品首页](https://fanyi-api.baidu.com/product/11)、[接口认证说明](https://fanyi-api.baidu.com/product/113)

5. **公开补丁不能内置制作者的私人 API 密钥。** XUnity 官方也明确要求不要分享密钥。朋友可各自配置凭据；另一方式是制作者运行代理服务保管密钥，但会增加服务器维护、配额及费用控制。发行包只携带验收译文，不携带私人凭据。[XUnity 密钥说明](https://github.com/bbepis/XUnity.AutoTranslator#about-authenticated-translators)

6. **Argos/LibreTranslate 支持离线英语→中文。** 当前官方模型表及公开索引有直接 `en → zh` 模型，版本 1.9，官方表标约 **67 MB**；另有繁体中文 `zt` 模型。需要额外下载并安装模型与运行依赖，之后可在本机推理，无在线按字符收费；总安装体积不止 67 MB。[官方语言表](https://docs.libretranslate.com/guides/supported_languages/)、[官方模型索引](https://github.com/argosopentech/argospm-index/blob/main/index.json)、[Argos 官方仓库](https://github.com/argosopentech/argos-translate)

7. **本地离线方案的代价是额外启动组件。** Argos 可作 Python 库直接使用；LibreTranslate 在其上提供 HTTP 服务，通常启动于 `127.0.0.1:5000`。要供游戏插件调用，就需要本地服务/辅助进程及接口适配；LibreTranslate 的 POST JSON 接口与 XUnity CustomTranslate 的 GET 纯文本格式不同。它不能直接变成一份很小、只丢进游戏目录就无需维护的词库；速度及占用需在本机实测。[LibreTranslate 安装](https://docs.libretranslate.com/guides/installation/)、[接口格式](https://docs.libretranslate.com/api/operations/translate/)、[Argos 用法](https://github.com/argosopentech/argos-translate)

8. **体验上应让翻译在后台发生。** 建议优先读已验收译文，再读本机草稿缓存；遇到未知英文先显示原文，同时后台排队初翻，成功后切换草稿字体，超时则继续显示原文。这样首次出现会有短暂等待，但断网/限流不会让对局停住。缓存也能减少后续等待和字符用量。这是设计建议，尚未实测延迟。[XUnity 缓存及排队机制参考](https://github.com/bbepis/XUnity.AutoTranslator#spam-prevention)

9. **自动中文仍只是草稿。** 已验收译文可随补丁发布并离线读取；自动结果应保留来源与待验收状态，以另一种中文字体区分，人工检查数值、否定词、触发条件、对象及术语后才晋升为正式词条。字体区分属于专用插件的状态呈现设计，翻译服务本身不会替我们执行验收；对本游戏的质量没有测试证据。

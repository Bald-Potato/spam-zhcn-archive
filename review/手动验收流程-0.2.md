# 0.2 手动验收：集中查看本次改动

从 Steam 启动，语言保持 English；按住 F8 看原文，松开恢复中文。

本版标题采用站酷快乐体，规则正文采用静态 Noto Sans SC ExtraBold 800。两类译文共用字体：已校对文本正常显示，未验收草稿加下划线。下划线只包文字，不包图标。

需要改标记时：关闭游戏，在 `BepInEx/config/com.spam.zhcn.cfg` 的 `[Appearance]` 中设置 `DraftStyle = Underline`、`Italic` 或 `None`，再启动。`None` 会取消草稿标记，译文的验收状态仍保留。

## 一次集中看这几处即可

1. **字体**：主菜单按钮、卡牌名应为漫画风字形；Tox 长说明、卡牌规则应比旧版明显粗。小字号仍须清晰，没有方框、截断或重叠。
2. **Tox 商店**：检查一个名称和一段长效果说明。两处都应有汉字；按住 F8 时与原文对照，确认目标、数量和触发条件。
3. **元素与重复图标**：选一张含两个不同元素或多段伤害的卡，比较 F8 原文的元素种类、每段数值和位置。多段效果本来就可能出现多个图标；不要把合法的多段效果当成重复。重点看同一个词是否被反复加图标、同一句是否出现嵌套链接。
4. **关键词**：点开暴击率、额外伤害、随机或状态提示。说明应正确，已有链接不会再次套一层链接；普通“治疗”等动词不应被误认成同名技能。
5. **中文语序**：范围是伤害范围而不是目标数量；重复次数、随机目标、敌我对象、百分比和正负号与原文对应。冷却增加 1 不自行扩写成“增加 1 回合”。

339 条完整效果说明已改用保守的固定句式，包括多元素、伤害范围、全体对象、治疗、额外伤害、消耗等。它们仍是草稿，不因程序生成就自动验收。含未知条件的复杂规则不作半句改写。

本版尚未完成所有 Tox 和卡牌的实战排版验收。你可以正常玩一轮后集中反馈，不需要频繁重启或逐项运行程序检查。

# 初版手动验收：边玩边检查即可

本机已安装补丁。直接从 Steam 启动 SPAM，游戏语言选 **English**。默认中文，**按住 F8 看英文，松开恢复中文**。黑体为已校对文本，宋体为未验收机译；不额外显示机译标志。

你不需要一次验收所有文本，也不需要反复重启游戏。建议每次正常游玩时选 3～5 张卡，顺手记录问题；一轮集中反馈即可。

## 一次怎样验收

1. **先看菜单与收藏。** 文字能读清、按钮能操作；用中文卡名及英文原名各搜一次。出现方块、截字、重叠或搜索不到时记录问题。
2. **打开一张卡的详情。** 看中文后按住 F8 对照英文，分别检查技能、被动、天赋和关键词说明。
3. **核对下面的规则清单。** 不只是数字相同，还要判断数字作用于谁、何时生效。不能确定就标“待复核”，保持机译草稿即可。
4. **在你愿意进行的对局中观察。** 留意技能升级、随机范围、状态层数和回合变化后，中文是否仍显示当前数值。是否进入联机对局由你选择，本轮自动检查没有完成完整对战验证。
5. **集中记录。** 用 Excel 或 WPS 打开同目录 `手动验收记录.csv`。筛选“类别”或搜索卡名、英文技能名，填写“修订译文”“验收结论”“问题备注”；其他列保留。

如果找不到对应行，直接记录卡名、技能名、英文原句、中文问题和发生位置即可。出现程序异常时，附游戏目录 `BepInEx/LogOutput.log` 的相关错误部分。

## 判定标准

| 检查内容 | 通过标准 | 应标为有问题的情况 |
| --- | --- | --- |
| 数值与单位 | 数量、百分比、范围、正负号、次数和单位与原文一致 | 漏掉“3 次”、把生命上限当当前生命、百分比变固定值 |
| 作用对象 | 自身、友方、敌方、目标、随机目标、全体区分清楚 | 把单体译成全体，或把友方译成敌方 |
| 触发与时机 | 回合开始/结束、造成伤害前/后、被摧毁、暴击等条件准确 | 漏条件，把“之后”译成“之前” |
| 否定与限制 | 不、不能、仅、首次、每次、最多、至少等意思保留 | “最多一次”变成“一次以上” |
| 消耗与结果 | 消耗、获得、移除、转移、附加伤害分得清 | 把消耗译成获得，把转移译成复制 |
| 术语一致 | 同一个关键词在卡牌和提示中含义一致 | 同一状态译法不一致并影响理解 |
| 图标与交互 | 元素图标、关键词链接、提示正常，可按 F8 看原文 | 图标丢失、点击提示无效、按键后文字不恢复 |
| 排版 | 常用分辨率下能完整阅读，没有方块和重叠 | 关键规则被裁掉、按钮文字不可辨认 |

验收结论可填：**通过 / 有问题 / 待复核**。错译或漏译、规则条件不清、关键文字缺失时不要标通过。纯粹不喜欢某个措辞，但规则含义正确，可以在备注写风格建议。

## 怎样把结果写进正式补丁

保存 CSV 后把本地路径或问题列表发给我。我会核对对应的英文原文指纹，检查数值和游戏标记，再集中导入修订、重打包。你无需手动编辑 DLL、游戏资源或 JSON。

只有明确通过的条目才迁入正式译文；有问题和待复核的条目继续保留草稿状态。游戏原文变更后，旧译文不会自动套到新规则上，也不会因重新生成译文包而被自动认定为已验收。

## 出问题时怎样恢复

- 只想看原文：按住 F8。
- 暂时不想联网初翻：关闭游戏，将 `BepInEx/config/com.spam.zhcn.cfg` 的 `AutoTranslate = true` 改成 `false`，再启动。
- 想停用汉化：关闭游戏，将同一文件的 `Enabled = true` 改成 `false`。
- 想卸载：关闭游戏，运行发行包 `uninstall.cmd`。本机缓存和配置会保留，方便以后继续。

背景故事和图片内的英文可以暂时跳过；机译接口失败时保留英文属于预期回退。正式规则文本仍显示宋体时，表示它尚未由人工确认，而不是程序漏读了验收状态。
